# Flamingo Qualitative Prompt

The collection does not yet contain a canonical Flamingo prompt or scoring rubric.

Do not invent, paraphrase, or substitute a generic prompt. Obtain the exact community wording and any associated protocol before running it. Once supplied:

1. save the exact text as `prompt.txt`;
2. record its SHA-256;
3. record whether the protocol is one-shot, agentic, or iterative;
4. preserve the generated output before repair;
5. apply only evaluation criteria supplied with the prompt or established by an accompanying rubric.

Until that information exists, mark Flamingo `Not tested` and use Tetris or the single-page platformer when an available qualitative comparison is required.
