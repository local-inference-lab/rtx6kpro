## Benchmarks and implementation findings
- Exporting DS4.1 Flash with a 6M KV pool reduced decode speed about 7-8% versus 2M. 2M sufficed for a main agent plus smaller subagents. [(jump)](https://discord.com/channels/1466898002793857221/1561901536412569640/1569130634604183675)
- FLARE-A16 run of local-inference-lab/Qwen3.8-Flash-Next-NVFP4-MXFP8-CSF-QAD scored pass_rate_1 48.1 and pass_rate_2 88.4; per-language pass_rate_2: cpp 83.8, go 81.5, java 81.3, javascript 95.9, python 94.1, rust 93.3. Same user reports vLLM scored above 90. [(1)](https://discord.com/channels/1466898002793857221/1528331644933767190/1569014161030258729) [(2)](https://discord.com/channels/1466898002793857221/1528331644933767190/1569015856606748733)
- Smith harness A/B on Qwen3.5-9B/RTX 5080: plan checker improved block puzzles 30/40 vs 9/37 and delivery routes 35/40 vs 20/40; bad-data handling went 0/32 to 32/32; reply-rule compliance 59/60 vs 44/60; 0/883 tasks wrongly blocked. Thinking mode was rejected. [(jump)](https://discord.com/channels/1466898002793857221/1466898004219789502/1569007207817679040)
- el8 reported that Flare supports engram caching of any size instead of all-or-nothing, and that Flare has a built-in prefix-caching subsystem, Selene, which can mix memory and disk. [(1)](https://discord.com/channels/1466898002793857221/1466898004219789502/1569019158568374364) [(2)](https://discord.com/channels/1466898002793857221/1466898004219789502/1569021232542650452) [(3)](https://discord.com/channels/1466898002793857221/1466898004219789502/1569021323848450074)
