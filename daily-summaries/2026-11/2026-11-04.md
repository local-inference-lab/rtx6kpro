## Releases and fixes
- Flare device error 6 in speculative decoding was traced to packages built with --vocabulary-parallel-sampling rejecting top_p below 1 during drafting; since #167 they advertise top_p 0.95–1, so a 0.95 request enters and the drafting step rejects it. PR #180 addresses this by keeping top_p at 1 for packages built with that flag, so top_p 0.95 requests no longer error and run at 1.0, with no kernel changes. The fix was tested on the public release-6fa01a4-main-20261101 image. - Flare Linux disk-engram prefill is single-threaded; adding read threads cut fresh 106k random prefill from ~10.5s to ~9.5s and 77k code from ~7.0s to ~6.2s, so it was not the root fix. Moving engrams from btrfs raid0 (2x gen5) to XFS on one gen4 drive cut 106k random from ~10.7s to ~7.8s, 77k code from ~7.0s to ~5.3s, and GPU idle wait from ~5.5s to ~2.5s. Btrfs on top of two gen5 drives gave ~0.4M reads/s per file, versus ~1.17M on one raw gen5 drive.
