# Daily Summary - 2026-09-28

## Key highlights
- Karmic Kraken Engram tables now load into RAM by default. On TP4 measured about 190 tok/s at C1, while disk tables ranged 78-134 tok/s; container needs about 230 GiB host RAM. Disk mode uses ENGRAM_TABLE_MEMORY=disk with seccomp=unconfined and memlock=-1. [(jump)](https://discord.com/channels/1466898002793857221/1547563567379906651/1554208083755016384)
- Fastokens 0.3.2 with VLLM_USE_FASTOKENS=1 gave 5.5-11.1x tokenizer speedup (720k to about 8M tok/s) on GLM-5.3-Flash-NVFP4-Spark (karmic-kraken 0928-6bd83bf, TP2, 2x RTX PRO 6000 Blackwell). Token counts were bit-identical at all eight sizes from 8k to 700k; build notes list a few prompts tokenized differently. ## Benchmarks and implementation findings
