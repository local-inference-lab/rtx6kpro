## Benchmarks and implementation findings
- Auldria ran Flare 972e28e44781d8d0c84d70ae434db92c36076a43 with WARMIND-1017-FLARE-CSF-gb202 ccc1d35, MTP 7 draft tokens, adaptive verification alpha 1, throughput scheduler, RAM embedding table, memory KV cache on 4x workstation cards at 600W (+75/+6000): faster than vLLM everywhere, fixing prior poor C8/C16/C32 and ~17K prefill results. [(1)](https://discord.com/channels/1466898002793857221/1561901536412569640/1568288153163530253) [(2)](https://discord.com/channels/1466898002793857221/1561901536412569640/1568330273114824715) [(3)](https://discord.com/channels/1466898002793857221/1561901536412569640/1568331640785207399)

When multi-GPU decode is far slower, BoxTops4Coochie suggests checking IOMMU/ASPM settings and considering ECC off with a +6000 memory offset.
